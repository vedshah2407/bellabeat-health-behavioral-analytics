# Bellabeat Health & Behavioural Analytics

## Project Overview

This project analyzes Fitbit smart device usage data to identify user activity, sleep, and behavioral patterns.
The goal is to generate actionable insights that can help Bellabeat improve user engagement, wellness tracking, and product marketing strategies.

---

## Business Objective

Bellabeat is a wellness-focused technology company that develops smart products for health tracking.
Using Fitbit fitness tracker data, this project explores how users interact with health metrics such as activity levels, sleep behavior, calorie burn, and exercise intensity.

The analysis aims to answer:

* When are users most active?
* How does sleep impact wellness metrics?
* What behavioral trends can be identified from user activity data?
* How can these insights support business and marketing decisions?

## Key Insights

### User Activity Trends

* Users show peak activity during morning and evening hours.
* Calorie burn and exercise intensity increase significantly during evening periods.
* Overnight activity remains consistently low.

### Sleep Behaviour Insights

* Most users sleep between 6–8 hours.
* Longer sleep duration generally improves sleep efficiency.
* Spending more time in bed does not always improve sleep quality.

### User Behaviour Patterns

* Active users show stronger consistency in daily movement.
* Sedentary users demonstrate lower engagement across wellness metrics.
* Sleep efficiency varies significantly across user groups.
